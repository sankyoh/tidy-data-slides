# 整然データが解析に役立つ理由

整然データと整然ではないデータを比較し、解析上の利点を説明する日本語のHTMLスライドです。講演の補足資料として公開しています。

## スライドを閲覧

[HTMLスライドを開く](https://sankyoh.github.io/tidy-data-slides/)

- 全13枚。Stataなどのソフトウェア操作の説明は含みません。
- 健診データは説明用の架空データです。
- 変数・観測・表の対応、集計・点検・更新のしやすさを比較します。
- ワイド形式も観測単位によっては整然データとなること、整然化だけで統計的妥当性が保証されないことを説明します。

## 操作

- 画面下の矢印、キーボードの左右キー、またはスワイプでページ送り。
- 目次: Oキー / 補足説明: Nキー / 全画面: Fキー。
- 画面の印刷ボタンから全スライドを印刷・PDF保存できます。
- `index.html`をダウンロードすると、オフラインでも閲覧できます。

## ファイル構成

- `index.html`: CSS、JavaScript、日本語フォントを内包した単一HTMLスライド。
- `.nojekyll`: GitHub Pagesで静的ファイルをそのまま配信するための設定。
